# EchoVerse 🌌

A full-stack storytelling platform where users can write, read, and react to stories. Built with the MERN stack (MongoDB, Express, React, Node.js), featuring a beautiful, modern UI.

## Features
* **User Authentication:** Secure login and registration.
* **Story Publishing:** Write, edit, and publish stories with custom tags and categories.
* **AI Mood Detection:** Automatically generates a cover gradient based on the emotional tone of the story.
* **Engagement:** Like, comment, and bookmark your favorite posts.
* **Anonymous Mode:** Post your thoughts anonymously.

## Tech Stack
* **Frontend:** React, Vite, raw CSS (Glassmorphism design)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose)
* **Authentication:** JSON Web Tokens (JWT), bcrypt
